# @yadeck/slide-components-basic

標準の Layout 一式(basic プラグイン)。表紙、章扉、自動レイアウト、2 列、カード、コード、画像、流れの図など。

YADECK は、AI が schema 付きの YAML に内容を書き、作り込みたいページだけを JSX で作るスライドジェネレータです。

```ts
import basic from "@yadeck/slide-components-basic";
export default defineConfig({ plugins: [basic] });
```

- ドキュメント: https://onfi.github.io/yadeck/
- リポジトリ: https://github.com/onfi/yadeck
