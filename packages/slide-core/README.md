# @yadeck/slide-core

YAML の読み込みと検証、tags で Layout を選ぶ DI コンテナ、静的 HTML への描画、JSON Schema の出力、CLI(`yadeck`)。

YADECK は、AI が schema 付きの YAML に内容を書き、作り込みたいページだけを JSX で作るスライドジェネレータです。

```sh
npx yadeck dev       # プレビュー
npx yadeck build     # dist/*.html に書き出す
npx yadeck check     # はみ出しの検査(playwright が必要)
```

- ドキュメント: https://onfi.github.io/yadeck/
- リポジトリ: https://github.com/onfi/yadeck
